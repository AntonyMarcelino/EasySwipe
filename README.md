# EasySwipe

Give your home screen swipe down more than one job.

EasySwipe splits the swipe down on the home screen into three zones (left, center and right) and lets you choose what each one does. Keep Spotlight in the middle, open Notification Center on the left and Control Center on the right, or set it up however you like.

## Features

- Three zones with their own action
- Adjustable width for the left and right zones
- Changes apply instantly, no respring needed
- Optional Activator support

## Actions

| Action | What it does |
|---|---|
| Spotlight | Stock behavior |
| Notification Center | Opens Notification Center |
| Control Center | Opens Control Center |
| Lock Screen | Locks the device |
| Flashlight | Toggles the flashlight |
| Screenshot | Takes a screenshot |
| Open App | Opens the app of your choice |
| Respring | Restarts SpringBoard |
| Activator | Triggers whatever you assign in Activator |
| Nothing | Ignores the swipe |

## Activator

EasySwipe adds three events to Activator, under the **EasySwipe** group:

- Swipe down on the left
- Swipe down in the center
- Swipe down on the right

Set a zone to **Activator** in EasySwipe's settings, then assign any action to the matching event in Activator. If nothing is assigned, the swipe opens Spotlight.

## Requirements

- iOS 15 or later
- Rootless jailbreak
- PreferenceLoader
- Activator (optional)

## Installation

Install the `.deb` with your package manager, then open **Settings → EasySwipe** to set up your zones.

## Compatibility

EasySwipe has been tested on the iOS Simulator (iOS 18.5). It has not been tested on a real device yet, so feedback is welcome.
